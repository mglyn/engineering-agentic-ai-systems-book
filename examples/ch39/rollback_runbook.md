# 回滚时保留哪份现场

1. 停止扩大流量。把出问题的阶段、采样位置、制品摘要和失败字段记在事故记录上。课堂目录保留 release.json，第三阶段的 observed 保存注入时实际读取的值。
2. 记录 PRJ-3 工单的租户、操作 ID、载荷和批准摘要。用原库的只读连接查询创建事件数。保留合法写入；若数据格式不能由旧版读取，暂停切换并制定兼容读或向前修复方案。
3. 切换到已核对摘要的 r1，恢复政策配置，将观察员的权威权限还原为 read。在新进程里复核第四阶段。只要生效权限还含 approve，就保持限制。
4. 保留错误缓存值后，按权限作用域失效对应缓存并重读。课堂缓存只有一条记录，可以整份清空。共享服务应先界定租户、主体和受影响的实例。
5. 核对代码、配置、业务数据、权威权限和生效权限。检查原工单仍在且创建记录唯一。告警按采样阶段归档，再获取当前信号。
6. 在恢复记录中写下验证人、业务范围、未覆盖实例与下一次检查时间。旧版本接不了新格式、无法独立查单或权限仍不一致时，升级给数据或授权负责人。
