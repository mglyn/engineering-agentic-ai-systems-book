# Exp-23-01 恢复与重投递

从仓库根目录执行 `python examples/ch23/session_replay.py`。只用 Python 标准库和 Ch36 的本地 TicketService。Windows、CPython 3.12.16 的一次实测原始记录在 reports/replay.json。输入、代码、表和图为本书原创或仓库内复用，采用项目 MIT 许可。20 种投递变体的执行顺序见 FAULTS；三条会话各运行一次。每次重新执行都会使用新的临时数据库，默认报告写到 outputs/ch23/replay.json。

预期输出 `replay 60/60; transcript-only tickets 2`。计数不符时命令退出非零；报告包含输入、快照、实际处置、独立存储计数和每次恢复的墙钟耗时。用于模拟文本的固定字符串不含操作键。负对照重试使用一个仍然有效的授权；实际系统如何重新取得授权要另行设计。

主要限制为受信本机、静态日志、单轮会话、每会话独占一个实验数据库。无跨机器时钟、网络服务、并发写入或真实身份系统。快照摘要防止实验中客户端持有错误副本，不能证明服务端存储未被篡改。实验的 v0 迁移覆盖单个字段名变化。
