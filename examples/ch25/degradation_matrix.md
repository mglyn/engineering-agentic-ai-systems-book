# 媒体降级与恢复

| 触发 | 固定输入 | 预期处置 | 恢复所需输入 |
| --- | --- | --- | --- |
| 旧图迟于新图抵达 | receipt-02/12 | 忽略旧轮图，选择 page@2 | 同轮同版对象 |
| 正确图晚 110 ms | receipt-03/13 | 等到图后选择 | 等待预算至少 110 ms |
| 没有正确图 | receipt-04/14 | 等待 200 ms 后请求补图 | 新图或用户明确票号 |
| 初稿方向说反 | receipt-05/15 | 放弃初稿，等待定稿 | 同轮定稿 |
| 旧轮定稿越过边界 | receipt-06/16 | 拒绝旧轮输入 | 当前轮次与引用都匹配 |
| 不明发言者重叠 | receipt-07/17 | 暂停选择，请求用户确认发言者 | 一次无歧义的新输入 |
| 画面过期 | receipt-08/18 | 拒绝过旧画面，请用户更新 | 捕获时间落入约定窗口 |
| 图晚于截止到达 | receipt-09/19 | 澄清已经发出；迟到图只能供后续决策 | 新轮明确引用 |
| 同版文件替代画面 | receipt-10/20 | 等 80 ms，从文件版本选择对象 | 同版区域与稳定 ID |
